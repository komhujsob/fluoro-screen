# FluoroScreen

Учебный проект по хемоинформатике. По каноническому SMILES и растворителю программа оценивает максимум эмиссии λₑₘ (нм), показывает до пяти ближайших хромофоров из вашей таблицы и указывает источники их измерений.

**Лабораторный сценарий.** Есть серия производных красителя и таблица уже измеренных соединений. Перед измерением нового производного можно получить ориентир для λₑₘ, посмотреть, какие аналоги его определили, и увидеть, совпадает ли их растворитель с заданным. Для практического применения сначала проверьте ошибку на отложенных соединениях из вашей серии.

## Запуск

Python 3.10+, стандартная библиотека. После клонирования из корня репозитория:

```bash
python3 fluoro.py inspect examples/synthetic.csv
python3 fluoro.py benchmark examples/synthetic.csv --predictions /tmp/fluoro-predictions.csv
python3 fluoro.py predict examples/synthetic.csv --smiles 'CCOc1ccccc1' --solvent ethanol
python3 -m unittest discover -s tests -v
```

`inspect` показывает, сколько строк исключено и сколько пар «молекула — среда» осталось. `benchmark` печатает метрики в JSON и при необходимости сохраняет таблицу построчных ошибок. `predict` возвращает оценку, список аналогов, их растворители, сходство и исходные значения.

## Входная таблица

Подготовьте CSV в UTF-8. Обязательные поля: `smiles,solvent,emission_nm`. Поле `source` можно заполнить DOI, идентификатором измерения или номером записи в лабораторном журнале. Поддерживаются также заголовки `Chromophore`, `Solvent`, `Emission max (nm)` и `DOI`.

Используйте канонический SMILES из одного инструмента и одно обозначение растворителя по всему CSV, например `ethanol`. В программе регистр и лишние пробелы нормализуются. Для сравнения с лабораторной серией держите сопоставимыми условия измерений, включая состояние образца и состав среды. Повторные строки с одинаковыми SMILES и растворителем сводятся к медиане, число строк и ссылки сохраняются. Строки с пропусками или нечисловой длиной волны исключаются и учитываются в отчёте.

Подходящий опубликованный набор для дальнейшей проверки — **DB for chromophore**, версия 3, Joung, Han, Jeong и Park. База содержит 20 247 записей по оптическим свойствам, в том числе данные по эмиссии. Исходная таблица лицензирована по CC BY 4.0. Если заголовки экспортированной версии отличаются, приведите три нужных столбца к схеме выше. [Данные Figshare](https://doi.org/10.6084/m9.figshare.12045567.v3) · [Описание набора в Scientific Data](https://doi.org/10.1038/s41597-020-00634-8)

## Как оценивается качество

- Базовый прогноз — медиана λₑₘ на обучающей выборке.
- kNN использует сходство Танимото по хешированным последовательностям из 1–4 токенов SMILES. При ранжировании добавляется 0,08 за совпадение растворителя. Каждый хромофор представлен одним измерением. Если нужного растворителя нет, берётся измерение, ближайшее к медиане для этого хромофора. Вес соседа равен квадрату его сходства.
- 20% уникальных входных SMILES идут в тест. Все растворители одного SMILES попадают в одну часть. Отчёт включает MAE, медианную абсолютную ошибку, RMSE и число прогнозов, у которых сходство со всеми соседями ниже 0,35. Этот порог эвристический.
- Разбиение зависит от каноничности входных SMILES. Близкие производные одной серии могут попасть в обе части. Для оценки на новых семействах красителей понадобится отдельный тест по химическим сериям. Сходство рассчитывается по записи SMILES, поэтому результат зависит от способа её канонизации. Токенизация проверяет допустимый текст, для проверки химической структуры нужен отдельный инструмент.

## Проверенный пример

Демонстрационная таблица содержит 20 **синтетических** значений и служит для проверки работы программы. При seed 42 в тесте четыре пары «хромофор — растворитель». MAE kNN составила **21,84 нм**, MAE медианы — **38,75 нм**. Эти цифры относятся только к демонстрации. Экспериментальный бенчмарк на Figshare пока не выполнен.
